A HTML CSS and JS project where a user clicks the given buttons "system check", "virus and threat protection", "Storage" and "Run Diagonistics". If the user clicks run diagonistics. it processes hypothetical files but then it shows that an unknown process has started and then shows the details of the user's device for example battery %age, screen size, time, etc and starts becoming distorted. The website then makes an attempt to restore it but fails and the screen becomes even more distorted.

This is all fictitious except the user device details and the system is not actually hacked/infected or anything along those words.

Built as a project for Hack Club's Zone Out YSWS [You Ship We Ship] Program.
